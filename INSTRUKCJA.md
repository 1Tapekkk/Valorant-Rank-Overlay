# Documentation

The current English documentation is in [README.md](README.md).

Use **START OVERLAY.cmd** to open the dashboard. Add `http://127.0.0.1:4321/overlay` as a Browser source in OBS, using the dimensions shown in the dashboard.

For sharing, use the clean archive in `releases/valo-rank-studio-source.zip`. Never upload `overlay/data/`, which contains your API key and private settings.
